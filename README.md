# Portal da Eletrônica

Portal educacional para explorar componentes eletrônicos por categoria e consultar explicações sobre quatro deles. Inclui modo escuro, alto contraste e interfaces administrativas demonstrativas de listagem, cadastro, edição, exclusão e categorias.

## Tecnologias

Node.js, Express, EJS, HTML, CSS e JavaScript.

## Executar localmente

1. Instale o Node.js.
2. No terminal, execute `npm install` e depois `npm start`.
3. Acesse http://localhost:3000.

## Estrutura

- `app.js`: dados de exemplo e rotas.
- `views/`: páginas EJS e trechos compartilhados.
- `public/`: estilos e JavaScript do navegador.

O painel não possui autenticação real, persistência ou operações de gerenciamento. Não use credenciais reais. As quatro páginas educativas incluem fotos e vídeos com legendas em português. As interfaces administrativas são demonstrações e não salvam alterações. A atualização do protótipo no Figma depende do acesso da equipe.
